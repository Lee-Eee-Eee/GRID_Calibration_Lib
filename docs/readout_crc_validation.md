# 14B/15B 旧解包产物修复

2026-10-25 对真实原始包与工作台产物进行逐事件比对。

## 原因

当前 584 字节事件包使用每包 38 条事件、14 字节事件步长。早期产物按 40 条、12 字节解析，事件数量增为正确值的 40/38，并错读幅度、基线、通道和 CRC 位置。用旧参数重解析同一份 Cs137、Co60 原始文件，可逐值重现历史 L0 的五列数据及全失败 CRC。

14B 当前读取预设 v3 正确；Cs137、Co60 尚未重建的历史 L1 被选作输入。15B 旧试算的原谱也来自上述旧 L0，错位值造成负幅度和高 ADC 伪尾。

## 真实复测

| 输入 | 按 38/14 解析的事件数 | CRC 失败 |
| --- | ---: | ---: |
| 14B Cs137 | 490,390 | 0 |
| 14B Co60 | 2,196,096 | 0 |
| 14B 源本底 | 388,018 | 0 |
| 15B 0C-265-131 | 410,514 | 0 |
| 15B 10C-270-141 | 374,908 | 0 |
| 15B m30C-290-118 | 496,318 | 0 |

15B `10C-270-141` CH0 在 1200 ADC 以上的占比由旧谱约 56.9% 变为正确谱约 1.23%。原始字节独立取值、标准库 CRC 复算均与新 Parquet 一致。CRC 有效的高 ADC 尾部与饱和脉冲继续保留。

原 15B 试算已重新解包全部 56 份 TB L0，CRC 和格式检查全部通过。14B 两源及本底已重建 L0/L1，并在相同 TB 参数下生成 12 组源峰参数。Co60 各通道用实测 Na22 参考定位两峰，在峰间谷分开独立窗口；每通道两峰的中心不同且按能量有序。后续可用联合双峰模型和窗口敏感性分析评估邻峰尾部带来的中心系统误差。

## 工作台行为

TB L0、EC L0/L1 预览统一使用 CRC 有效事件；部分失败时记录输入和排除数量，全部失败时提供重新解包入口。EC 的“重建此源”只运行该观测及本底的 L0/L1，保留所选能线和通道。源流程按实际文件名和曝光匹配，不把源分组名称当作观测文件名。

EC L2 聚焦时，纵轴按可见范围内的计数、拟合曲线和误差棒缩放，避免窗口外强暗噪声压低高能峰显示；整谱视图恢复自动范围。线性轴保留负净计数和零值。

新产物写入试算目录。诊断脚本、逐事件比对、输入哈希、窗口修订和作业记录保存在工作区 `runs/20261025-{input-review,14b-crc-diagnosis,15b-tail-diagnosis}/`。
