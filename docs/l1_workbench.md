# L1 工况谱复核

进入 TB L1 后，左侧列出已有 L0 的工况文件。搜索支持文件名与已读取的温度、偏压；状态筛选区分已有拟合、需检查、待拟合。上一项、下一项及文件列表中的上下方向键沿筛选结果切换，保持当前通道。右侧四张通道卡显示峰位、R² 和当前状态，点击卡片查看对应谱。

主图叠加计数谱、高斯峰加背景模型及背景分量。下方残差使用同一组实际直方图 bin，定义为 `(计数 − 模型) / sqrt(max(模型, 1))`，虚线为 ±3。主图与残差横轴联动缩放。

拖动两条蓝色边界或输入 ADC 上下限后，点击“拟合当前通道”。只计算当前文件、当前通道，另外三个通道的参数保留。改窗后切走会保存修订，待拟合筛选可找回这些文件。“拟合此文件 · 四通道”和顶部当前文件计算均处理四个通道；计算范围选择全部数据后处理所有工况。

批量拟合按文件、通道记录结果和错误，单个通道失败时，其它完成的结果仍保存。需检查卡片可下钻至对应谱，调整窗口或在自动寻峰设置中指定实测噪声上界。失败通道已有的曲线可继续复核，但该旧结果不参加新的 TB L2 聚合。运行记录保存本次请求的文件、通道、配置及逐文件耗时。

工作台继续使用库内 `TBL1Processor` 与共同寻峰器。`POST /api/runs/<id>/jobs` 可传入 `layer: "TB_L1"`、`stem` 与 `fit_channels: [0]` 请求单通道；省略 `fit_channels` 时计算四通道。`GET /api/runs/<id>/l1-overview` 读取文件和四通道结果索引，无需计算 TB 曲面。
