# TB L1 / EC L2 谱复核

TB L1 顶部的“拟合质量总览”按当前分析通道展示实测温度、偏压散点。默认用颜色与标记区分质量通过、拒绝、拟合失败、改窗待拟合、已屏蔽和未判定；可切换到已有 R² 或约化 χ²（`fit_quality.redchi`）。状态直接读取已保存的 `fit_quality.accepted` 和拟合尝试，未提供质量判定的历史记录单列为“质量未判定”。

“当前通道筛选”可集中查看需复核点；文件名搜索与下方列表共用。筛选保持该通道全部工况的温偏坐标范围与数值色标。点击图中点或展开工况明细选择文件，打开同一通道的能谱、拟合窗口和残差；“返回质量总览”回到地图。坐标重合的记录分别保留，缺坐标的记录可从明细复核。

改窗后总览立即显示“改窗待拟合”；保存、单通道重新拟合及屏蔽/恢复后同步更新。屏蔽为独立标记，失败或待拟合点被屏蔽后仍可通过“已屏蔽”筛选找到。10B、11B CH3 保留“拟合方案待定”和谱复核入口，缺少温偏坐标时在明细中选择。

进入 TB L1 后，左侧列出已有 L0 的工况文件。搜索支持文件名与已读取的温度、偏压；状态筛选区分已有拟合、需检查、待拟合。上一项、下一项及文件列表中的上下方向键沿筛选结果切换，保持当前通道。右侧四张通道卡显示峰位、R² 和当前状态，点击卡片查看对应谱。

主图叠加计数谱、高斯峰加背景模型及背景分量。下方残差使用同一组实际直方图 bin，定义为 `(计数 − 模型) / sqrt(max(模型, 1))`，虚线为 ±3。主图与残差横轴联动缩放。

拖动两条蓝色边界或输入 ADC 上下限后，点击“按当前窗口拟合”。顶部当前文件入口执行相同操作，保留当前工况与通道。自动选窗收在同一谱区，两种入口都返回同一区域的结果反馈。批量入口处理全部工况；单文件多通道操作作为独立次入口。改窗后切走会保存修订，待拟合筛选可找回这些文件。

EC L2 主图同样显示当前校正谱、当前窗口及峰和背景曲线，下方显示按信号与本底传播误差计算的残差。能线可搜索、前后切换；所选能线与通道在单文件流程结束后保留。能量关系总览放在 EC L3。两层的“下一层”按钮只导航，计算由目标层的入口执行。

EC L2 当前窗口拟合只更新所选文件、通道及能线，源的其他能线和其他通道继续保留。各点分别保存所用 TB 版本；逐点重算累计覆盖当前读取配置，首次拟合一个点不会把整组能量标成完成。

10B、11B CH3 标为“塑料闪烁体 · 康普顿响应，拟合方案待定”，可看谱和拖窗，暂不执行高斯拟合。其余三通道的批量处理、状态筛选及下一层覆盖按 CH0–2 计算；其他载荷保留四通道流程。

批量拟合按文件、通道记录结果和错误，单个通道失败时，其它完成的结果仍保存。需检查卡片可下钻至对应谱，调整窗口或在自动寻峰设置中指定实测噪声上界。失败通道已有的曲线可继续复核，但该旧结果不参加新的 TB L2 聚合。运行记录保存本次请求的文件、通道、配置及逐文件耗时。

工作台继续使用库内 `TBL1Processor` 与共同寻峰器。`POST /api/runs/<id>/jobs` 可传入 `layer: "TB_L1"`、`stem` 与 `fit_channels: [0]` 请求单通道；手动入口明确传 `automatic_window:false`，自动入口传 `true`。省略 `fit_channels` 时处理当前载荷支持的通道。`GET /api/runs/<id>/l1-overview` 读取文件和通道结果索引，无需计算 TB 曲面。自动工况辅助与本轮真实复测见 [寻峰说明](peak_finding.md)及 [10B 复测](tb_peak_validation_10b.md)。
