# N5 官方采集预设

从工作区根目录注册已复制的数据目录：

```powershell
calibration_lib/.venv/Scripts/python.exe -X utf8 -m calibration_lib.tools.init_n5_preset --workspace . --raw-root "D:/GRID-calibration-data/Seafile/四天格"
```

命令读取副本中的 `温度偏压/N5/*_manifest.json`，只采用 `official=true` 的
6温度×8偏压共48个唯一正式工况。事件/HK按归档 `base_sci_*`、`base_hk_*` 唯一配对，
保留原 manifest 的名义温压与采集标记。当前副本还可索引72份唯一的 X 射线照射文件。
全部输入路径相对于所选数据根目录；XML、规则和目录关联写入工作区 `runs/_presets/`。

新建试算选择相同目录后可自动匹配该预设，使用保存的版本。再次执行命令时，配置相同则复用原版本；
配置改变则给同名 N5 预设发布新版本。

事件协议是584 byte、38×14；HK使用独立182 byte定义，CRC在180 byte。
温度使用 `sipm_temp/100−273.15 °C`，偏压字段使用 `sipm_voltage/1000 V` 的遥测监测电压口径。
原报告区分名义箱温与 SiPM 实测温度；温偏拟合使用 HK 实测值。
报告没有电流压降修正的电子学依据，预设保留监测电压定义。
TB参考源为Am241，主能线59.54 keV。谱范围0–65536 ADC、1 ADC/bin，覆盖16 bit原始峰值字段。

N5 `x/N5/README.md` 说明：照射某通道时，另一个照射文件中的**同一物理通道**是其本底；
两文件须分别按时长归一化，并传播计数率方差。该预设保留EC L0/L1检查入口，
将EC L2/L3标记为不支持，并保存具体原因，等待对应配对接口。

真实代表工况 `T-10_B28` 的完整事件/HK均通过CRC：520752事件、349个HK包。
整段HK平均温度为2.082/1.543/1.669/1.202°C，与原报告2.08/1.54/1.67/1.20°C相差不超过0.003°C。
默认自动拟合四通道中心为274.50/269.15/261.14/301.96 ADC，均通过当前统计质量筛选；
实际幅度17–8678 ADC，没有越过所选直方图范围。
